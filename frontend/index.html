How PIE builds its knowledge

1 · DiscoverScreens, forms, APIs, services and database objects from the ERP source.
2 · MapScreen → API → business logic → SQL → tables, with file and line evidence.
3 · ExplainAI writes explanations from the extracted facts only, labelled as AI-derived.
4 · StoreEverything is kept in the Qdrant knowledge base that the chat searches.

Verified facts come straight from the sources. AI-derived text and anything marked “needs review” should be checked with product before external use.
